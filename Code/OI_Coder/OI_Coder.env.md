# 运行环境要求

## Visual Studio Code

- **版本要求**：1.110 及以上（推荐 1.117 及以上）
  - ⚠️ 已知 1.119 版本存在可能影响使用的 bug，请避免使用该版本。
- **推荐插件**：
  - Python
  - GitHub Copilot
  - Copilot Terminal Tools - _mijur_
  - C/Cpp DevTools

## 编译与运行环境

### GCC / G++
- **最低版本**：8.0.0
- **推荐版本**：9.3.0 及以上

### Python
- **最低版本**：3.5
- **推荐版本**：3.9 及以上

## 额外自备

- **AI API Key**：请自行准备并配置有效的 API 密钥（如 DeepSeek API Key 或其他兼容的 AI 服务密钥）。
