# OI_Coder

专为信息学竞赛（OI）设计的 AI 智能体，聚焦 C++ 竞赛代码的调试、优化与验证。

## 使用方法

### 1. 在 VS Code 中使用

确保已安装 [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) 和 [Copilot Terminal Tools](https://marketplace.visualstudio.com/items?itemName=mijur.copilot-terminal-tools)。在 Chat 输入框中输入 `@NOI-Coder` 即可调用。

### 2. 支持的任务类型

| 任务         | 说明                                 | 示例                              |
| ------------ | ------------------------------------ | --------------------------------- |
| **完成题目** | 根据题目描述编写完整 C++ 代码        | "实现洛谷 P1001 的 A+B 问题"      |
| **修正错误** | 审查并修复代码中的语法/逻辑/效率问题 | "以下代码为什么 WA？[代码]"       |
| **优化代码** | 在保证正确性的前提下降低时间复杂度   | "将 O(n²) 优化为 O(n log n)"      |
| **对拍验证** | 生成随机数据并与暴力解比对           | "对拍以下代码，生成 200 组数据"   |
| **构造数据** | 生成随机/边界/极端测试数据           | "为 MST 题目生成 50 组随机图数据" |
| **解释算法** | 分析代码使用的算法及其复杂度         | "解释这段代码用了什么算法"        |

### 3. 对拍流程

1. 准备 C++ 解题代码（`sol.cpp`）和暴力参考代码（`bruteforce.cpp`/`.py`）
2. Agent 自动生成随机数据生成器 `gen.py`
3. 编译并运行对拍，报告差异
4. 根据结果给出修改建议

详细说明见 [`OI_Coder.agent.md`](./OI_Coder.agent.md)。

### 4. 环境要求

- **VS Code**：1.110+（推荐 1.117+，避开 1.119）
- **GCC/G++**：8.0.0+（推荐 9.3.0+）
- **Python**：3.5+（推荐 3.9+）
- **推荐插件**：Python、C/Cpp DevTools
- **AI API Key**：需自行准备并配置

详见 [`OI_Coder.env.md`](./OI_Coder.env.md)。
