## Agent 一览

#### OI_Coder

- 专为信息学竞赛（OI）设计的 AI 智能体，聚焦 C++ 竞赛代码的调试、优化与验证。

- **核心能力**
  - **C++ 代码审查与修复**：检查语法、逻辑与效率问题，输出带中文注释的修正代码。
  - **Python 测试数据生成**：自动生成随机/边界测试数据，支持数据自校验。
  - **自动对拍验证**：编译 C++ 代码并与暴力解比对结果，发现差异时输出错误用例及修改建议。

- **特点**
  - 全程中文输出（代码变量/注释可中可英）
  - 内置智能比较（忽略空白、浮点容差、顺序无关）
  - 可调用 read/edit/execute/browser 等工具
  - 支持多步骤任务顺序执行

#### OI_Coder_v2

- 专为算法竞赛设计的 AI 智能体，v2 重构版，覆盖 C++ 竞赛代码的编写、调试、优化与验证。

- **核心能力**
  - **完成题目**：根据题目描述编写完整 C++ 代码，含题意抽象、算法设计、复杂度估算等完整流程。
  - **修正错误**：系统化排查 CE/WA/TLE/MLE/RE 等错误，覆盖显性错误与隐性问题。
  - **优化代码**：降低时间复杂度，运用卡常、快读、滚动数组等竞赛优化技巧。
  - **对拍验证**：使用 Python + `subprocess` / `CYaRon` 自动对拍，比对目标解与暴力解。
  - **构造数据**：生成随机/边界/特殊结构/hack 数据，优先使用 `CYaRon` 库。
  - **解释算法**：阐述算法思想、实现细节、复杂度分析与正确性证明。

- **特点**
  - 基于 v1 重构，工作流程更细化、更可操作
  - 内置通用规范（文件管理、代码风格、沟通规范、安全规范）
  - 集成 `pylance-mcp-server/*` 工具，增强 Python 代码分析能力
  - 无子 Agent 依赖，内置全部能力
  - 全程中文输出
